# Kumili Vinesh Portfolio

React + Vite + Tailwind CSS + Framer Motion + Lucide.

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # outputs dist/

All content and links live in `src/data.js`. Replace every URL containing `YOUR-`.
Resume: `public/Kumili_Vinesh_Resume.pdf`.

Deploy: Vercel (import repo, framework Vite) or Netlify (build `npm run build`, publish `dist`).
